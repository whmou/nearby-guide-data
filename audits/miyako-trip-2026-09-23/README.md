## 查核分工與原始紀錄

四批舊資料、兩批新增資料，各有獨立的逐筆來源／故事事實／Google 驗證方式。再由另外兩位 reviewer 做定位核對與 16 篇風險取樣的故事核對，主流程整合修正。

- `existing-1.json`～`existing-4.json`、`new-north.json`、`new-south.json`：本批唯一認領清單；並非只憑完成通知就接受。
- [定位複核原始發現](maps-crosscheck.md)、[敘事複核原始發現](editorial-crosscheck.md)：保留當時快照與限制，不能當作後來所有改動的無條件認證。
- [browser/](browser/)：公開 Chrome 查核的最小事實摘錄，保存具名 URL、圖釘與搜尋候選，**不公開評論、評分或照片**。`opened_named_place` 與 `search_candidate_only` 分開。
- reviewer 文中 `viewer-qa` 路徑指本機私人查核檔；公開讀者請用 `browser/` 摘錄和逐筆 JSON 原始 URL。私人檔未放進資料包。
- `seals.json`：來源 YAML 與調查 JSON 的 SHA-256 快照，用於阻擋未複核的後續修改；hash 不是事實查核。
